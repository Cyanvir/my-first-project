1. 常用编译选项

-o	指定输出的可执行文件名（不写的话默认输出a.exe/a.out）	gcc main.c math_utils.c -o calculator

-c	只编译（把.c变成.o目标文件），不链接成可执行程序	gcc -c main.c → 生成main.o；gcc -c math_utils.c → 生成math_utils.o

-g	给程序加调试信息（后续用 GDB 调试必须加这个选项）	gcc main.c math_utils.c -g -o calculator_debug

-Wall	显示所有警告（比如变量未使用、类型不匹配，帮你找 bug）	gcc main.c math_utils.c -Wall -o calculator

-std	指定 C 语言标准（比如-std=c99用 C99 标准，-std=c11用 C11）	gcc main.c math_utils.c -std=c99 -o calculator

2. 常用 GDB 命令
进入 GDB 后，用这些命令调试：

break 行号/break 函数名	设置断点（程序运行到这里会暂停）	break main（在 main 函数开头设断点）；break 5（在第 5 行设断点）

run（缩写r）	运行程序（从开头跑到断点处暂停）	r

next（缩写n）	单步执行（不进入函数内部）	按n键，程序执行下一行

step（缩写s）	单步执行（进入函数内部）	比如执行到add(5,3)时，按s会进入add函数里

print 变量名（缩写p）	查看变量的值	比如p a（查看变量 a 的值）

continue（缩写c）	继续运行程序（从当前断点跑到下一个断点）	c

quit（缩写q）	退出 GDB 调试	q
