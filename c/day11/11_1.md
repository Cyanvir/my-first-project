指针的比较
在 C 语言中，可以比较指针来确定它们的关系。指针比较主要用于确定两个指针是否指向相同的内存位置或确定一个指针是否位于另一个指针之前或之后。

指针可以用关系运算符进行比较，如==、!=、<、>、<= 和 >=。如果 p1 和 p2 指向两个相关的变量，比如同一个数组中的不同元素，则可对 p1 和 p2 进行大小比较。
相等比较 (== 和 !=): 用于判断两个指针是否指向相同的内存位置。
大小比较 (<, >, <=, >=): 通常用于指针遍历数组或内存块时，判断一个指针是否在另一个指针之前或之后。
需要注意的是，指针比较只有在指向同一个数组或同一内存块时才有意义，否则行为未定义。

指针数组：
若要给指针数组输入字符串，必须先为每个指针分配可写内存：
char *names[4];
// 先分配内存，再输入
for (int i=0; i<MAX; i++) {
    names[i] = malloc(20); // 分配20字节可写内存
    scanf("%s", names[i]);
}
指针数组在C中非常有用，特别是在处理具有不定数量元素的数据结构时，如动态分配的字符串数组或动态创建的结构体数组。

加指针（int *arr）和 “伪无指针”（int arr[]）的核心区别
1. 本质上：完全等价，没有任何区别
C 语言标准规定：函数参数中的int arr[]是int *arr的语法糖（编译器会自动把int arr[]解析成int *arr）。
arr[i] 等价于 *(arr + i)：不管写int *arr还是int arr[]，访问数组元素的底层逻辑都是 “指针偏移 + 取值”；
函数接收的都是数组首元素的地址，不是整个数组的拷贝。
2. 写法上：int *arr更显式，int arr[]更易读
写int *arr：明确告诉程序员 “这里接收的是指针”，符合 C 语言数组传参的底层本质；
写int arr[]：用数组的写法，更直观体现 “这个参数是用来处理数组的”，对新手更友好。
